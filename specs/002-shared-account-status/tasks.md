## Dependencies and parallel work

- Setup precedes the shared implementation. T001 and T002 start independently. T003 supports the storage and service tests. After T003, T004 through T006 and T008 have distinct outputs. T007 and T009 establish the effective grant and state semantics before T010 exposes them.
- US1 and US2 can implement against T010 in parallel. Within US2, agents can implement Hermes, Omnigent, the xFactory-Hermes path, and worker metadata independently once the deployment paths and contract are confirmed. Coordinate the final worker pin and pilot enrollment after these changes converge.
- US3's end-to-end UI cases depend on US1's commands. Database concurrency behavior ships in the shared foundation. The final qualification depends on all three stories.

The first demonstrable increment is one status service and two desktops. The first shared release includes Hermes and the two independently scoped factory instances. Further instances use the same contract and prove their actual launch paths before enrollment.
